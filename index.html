Google Sheets Setup Guide

  1. Open Google Sheets → create new spreadsheet → name it Expense Tracker DB
  2. Create 3 tabs: Transactions, Users, Config
  3. In Transactions tab, add row 1 headers:
    id | date | type | category | source | description | amount | payment_mode | credit_card | user | notes | timestamp | reconciled
  4. In Users tab, add row 1 headers: id | name | color | created_at
  5. Copy Sheet ID from the URL (between /d/ and /edit) → paste above
  6. Go to Extensions → Apps Script → delete default code → paste the script below
  7. Click Deploy → New deployment → Web app → Execute as: Me → Who has access: Anyone → Deploy
  8. Copy the /exec URL → paste above → click Test connection
