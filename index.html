Google Sheets setup guide

Follow these steps to connect this tracker to a Google Sheet as your live database:

  1. Open Google Sheets → create a new spreadsheet → name it Expense Tracker DB
  2. Create 3 sheets/tabs: Transactions, Users, Config
  3. In Transactions sheet, add headers in row 1:
    id | date | type | category | source | description | amount | payment_mode | credit_card | user | notes | timestamp | reconciled
  4. In Users sheet, add headers: id | name | color | created_at
  5. Copy the Sheet ID from the URL (between /d/ and /edit) and paste it above
  6. Go to Extensions → Apps Script in your sheet
  7. Delete any default code and paste the Apps Script code (click button below)
  8. Click Deploy → New deployment → Web app
  9. Set Execute as: Me and Who has access: Anyone
  10. Click Deploy → copy the Web App URL → paste it above
  11. Click Test connection to verify everything works
